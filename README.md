# CSV Automation Tool

A lightweight Python script designed to automate CSV processing tasks such as calculating averages, filtering rows based on conditions, and generating clean output for analysis.  
This project demonstrates foundational skills essential for Technical Support, Implementation, and Automation Engineering roles: scripting, data processing, debugging, and Git branching workflows.

---

## Features

- **Processes CSV files and calculates averages**  
- **Filters rows where score > 85**  
- **Demonstrates scripting, automation, and Git branching (feature branch → merge)**  
- Easily extendable for additional rules, filters, or summary metrics

---

## Requirements

- Python 3.8+  
- Basic familiarity with running Python scripts  
- Git (optional, if cloning the repo)

No external packages are required — only Python’s built-in modules are used.
